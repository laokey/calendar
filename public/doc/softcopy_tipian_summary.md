# 《芝麻日历》软著申报摘要说明

## 一、业务和功能介绍

芝麻日历是一款面向家庭、多成员协同及日常生活管理场景的移动端应用，项目目标是将家庭事务、日程安排、任务执行、成员互动和设备协同等能力整合到同一套系统中，帮助用户以更低成本完成家庭日历管理和信息同步。系统围绕“家庭共用日历”这一核心目标展开，兼顾个人使用体验与多人共享需求，支持 Android、iOS 等移动端设备使用。

软件核心功能模块主要包括：账户登录注册与找回密码、动态通知与邀请处理、日历事项管理、任务管理、奖励与惩罚管理、餐食计划管理、相册管理、贺卡功能、设备管理、用户管理以及第三方日历同步等。其中，日历事项模块支持按月视图和周视图查看事项、新增编辑删除事项、设置参与成员及重复规则；任务模块支持新增任务、完成任务、筛选任务和配置显示规则；奖励与惩罚模块用于家庭成员积分激励；餐食模块用于一周餐食安排；相册和贺卡模块承担家庭内容留存与互动表达；设备管理和用户管理则用于完成家庭设备绑定、成员协作和权限管理。

在业务流程上，用户通常先完成注册登录，再进入首页查看动态、通知和主要功能入口；随后可根据需要创建日历事项、任务或奖励内容，并通过成员维度进行协同分配；在设备和成员接入后，系统还支持邀请处理、设备激活、用户管理和多端数据共享；对于有外部日历需求的用户，系统提供 Google、Outlook、iCloud、订阅链接等同步能力，用户可完成第三方账号绑定、日历选择、同步状态查看和结果确认，从而形成“注册登录 -> 家庭成员协同 -> 日历/任务/奖励等业务操作 -> 设备与同步扩展”的完整功能路径。

## 二、项目实现

本项目整体采用 UniApp + Vue 3 技术架构实现，面向移动端多平台统一开发，兼顾 Android 与 iOS 的运行适配。前端页面按功能域拆分为登录注册、日历事项、任务、奖励、餐食、相册、设备、用户和同步等多个模块，并结合本地状态管理、接口请求封装、国际化、多端权限处理等能力完成业务实现。项目在设计思路上强调模块清晰、流程闭环和可扩展性，既覆盖家庭场景下的核心事务管理，也为第三方同步、设备协同和后续功能扩展预留了稳定接口。

我负责的内容主要集中在移动端前端实现和业务流程打通，包括核心页面开发、接口对接、业务状态流转、权限处理、多端适配及交互优化等工作。在结果上，完成了用户登录注册、日历事项、任务、奖励惩罚、设备管理、用户管理及日历同步等主要模块的页面与逻辑实现，能够支撑从用户进入系统到完成家庭事务协同、设备接入和第三方日历同步的完整链路。同时，对关键接口进行了统一封装，对页面参数传递、数据映射、状态回显和异常提示做了规范处理，提高了整体可维护性和稳定性。

项目实施过程中，较大的难点主要集中在多模块业务耦合、接口字段对齐、多端兼容和第三方日历同步链路上。首先，家庭日历场景涉及成员、设备、事项、任务、奖励等多类数据对象，页面之间的跳转和状态回写较多，容易出现参数不一致或状态错乱的问题；其次，部分后端接口存在固定字段命名、参数必须通过 Query 传递、表单提交格式约束等要求，需要前端严格对齐；再次，iOS/Android 在权限申请、安全区域、WebView 显示及页面适配上存在差异，需要逐项验证和修正；另外，Google、Outlook、iCloud 等第三方日历同步在账号绑定、回调处理、日历列表获取和同步状态查询上均有不同规则。针对这些问题，我通过统一封装请求方法、梳理同步链路参数、补齐页面兜底逻辑、增加状态轮询和错误提示、优化安全区与导航栏适配等方式完成解决，最终保证了主要功能模块可以稳定运行并形成较完整的产品闭环。
