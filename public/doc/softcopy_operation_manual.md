# 《芝麻日历》软件操作说明书

## 1. 文档说明

本文档为“芝麻日历”软件的操作说明书，用于说明软件的运行环境、安装启动方式、主要功能模块及具体操作流程，可作为软件著作权申请材料中的操作说明文档使用。

建议在正式提交软著材料前，结合本说明书内容补充实际运行截图，并按章节顺序排版导出为 PDF 或 Word 版本。

## 2. 软件基本信息

- 软件名称：芝麻日历
- 软件版本：V1.0.0
- 软件类型：移动端家庭日历与事务管理软件
- 技术架构：UniApp + Vue 3
- 运行平台：Android、iOS
- 主要用途：为家庭或多成员场景提供日历事项管理、任务管理、奖励惩罚、餐食计划、相册管理、设备管理、用户邀请与同步日历等功能

## 3. 运行环境

### 3.1 硬件环境

1. 智能手机或平板终端一台
2. 设备具备触控操作能力
3. 可正常连接互联网

### 3.2 软件环境

1. Android 或 iOS 操作系统
2. 已安装芝麻日历客户端
3. 网络连接正常

### 3.3 权限环境

软件运行过程中可按功能需要申请以下权限：

1. 相机权限：用于拍摄头像、上传图片、制作贺卡、上传相册内容
2. 相册权限：用于从本地相册选择图片或视频
3. 通知权限：用于事项提醒、任务提醒、消息通知
4. 日历权限：用于同步本地或第三方日历
5. 地理位置权限：用于部分扩展能力或设备能力支持

## 5. 用户登录与注册

### 5.1 用户注册

1. 在登录页点击注册入口
2. 输入注册邮箱、验证码及相关信息

1. 在登录页输入账号和密码

1. 在登录页点击“忘记密码”或“重置密码”

## 7. 动态、通知与邀请功能

### 7.1 动态查看

1. 进入动态页面
2. 选择“动态”标签
3. 查看成员完成任务、取消任务等操作记录
4. 点击某条动态可进入详情页查看详细内容

### 7.2 通知查看

1. 切换到“通知”标签
2. 查看系统消息、公告或提醒信息
3. 点击通知项可查看详情

### 7.3 邀请处理

1. 切换到“邀请”标签
2. 查看收到的邀请信息
3. 点击“确定”可接受邀请
4. 点击“取消”可拒绝邀请

## 8. 日历事项管理

### 8.1 查看日历

1. 进入日历模块
2. 软件支持按“月视图”或“周视图”查看事项
3. 用户可点击左右切换按钮浏览不同时间范围
4. 点击日期单元格可查看当日事项

### 8.2 新增事项

1. 在日历页点击右下角新增按钮
2. 进入“添加事项”页面
3. 输入事项标题
4. 选择全天或设置开始、结束日期与时间
5. 选择参与成员
6. 输入描述信息
7. 设置重复规则
8. 点击保存完成新增

### 8.3 编辑事项

1. 在日历页面点击已有事项
2. 进入事项详情页
3. 点击编辑按钮
4. 修改事项内容后保存

### 8.4 删除事项

1. 打开事项详情
2. 进入编辑或删除操作入口
3. 确认删除后，系统移除该事项

## 9. 任务管理

### 9.1 查看任务

1. 进入任务模块
2. 页面按日期显示待完成任务和已完成任务
3. 用户可切换顶部日历展开方式查看指定日期任务
4. 可通过成员筛选查看对应成员任务情况

### 9.2 新增任务

1. 点击右下角新增按钮
2. 进入“添加任务”页面
3. 输入任务标题
4. 设置表情、日期、时间、优先级、归属成员
5. 设置奖励心数或其他附加信息
6. 保存任务

### 9.3 完成任务

1. 在任务列表中找到目标任务
2. 点击任务右侧完成按钮
3. 系统将任务移动至“已完成”区域，并同步更新动态或积分状态

### 9.4 编辑或删除任务

1. 长按任务或通过滑动操作打开功能菜单
2. 选择编辑或删除
3. 按提示完成操作

### 9.5 设置任务显示规则

1. 进入任务设置页面
2. 可配置是否显示已完成任务
3. 可配置是否显示逾期任务
4. 可设置排序规则

## 10. 奖励与惩罚管理

### 10.1 查看奖励列表

1. 进入奖励模块
2. 顶部可切换不同成员
3. 页面显示该成员当前心数及可执行的奖励或惩罚项目

### 10.2 新增奖励或惩罚

1. 点击新增按钮

3. 输入标题

5. 设置增减心数

### 10.3 执行奖励或惩罚

1. 在列表中选择某条奖励或惩罚项目
2. 点击兑换或执行按钮
3. 系统更新成员心数并显示结果弹窗

### 10.4 奖励显示设置

1. 进入显示设置页面
2. 可配置是否展示已完成项目
3. 可设置排序规则

### 11.1 查看周餐食计划

### 11.4 餐点详情查看

1. 点击某条餐点记录

## 18. 异常处理说明

### 18.1 网络异常

当网络中断或服务器无响应时，系统会弹出提示信息，用户可在网络恢复后重新操作。

### 18.2 数据校验异常

当用户未输入必填项或输入格式错误时，系统会给出提示，例如：

1. 标题不能为空
2. 邮箱格式不正确
3. 未选择成员
4. 下载地址缺失

### 18.3 权限异常

如系统权限未开启，软件会提示用户前往系统设置授权后继续使用相关功能。

## 19. 软件退出与结束使用

1. 用户完成操作后，可通过系统返回键或页面返回按钮退出当前页面
2. 返回主界面后，可切换至其他模块继续使用
3. 关闭应用即完成本次使用

芝麻日历软件面向家庭及多成员协同场景，提供事项、任务、奖励、餐食、相册、设备、用户与同步日历等功能。系统具备完整的账户管理、数据录入、列表查看、编辑修改、状态更新和设置管理能力，能够满足家庭日程管理和设备协同使用需求。
